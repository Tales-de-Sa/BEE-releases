# BEE — Releases

Este repositório hospeda **somente os instaladores compilados** (`.exe` para
Windows, `.deb` para Linux/Debian/Ubuntu) de cada versão publicada do BEE,
sistema de auxílio administrativo fiscal desenvolvido pela THARK TECNOLOGIA.

O código-fonte do BEE **não está aqui** — fica no repositório privado
`Tales-de-Sa/BEE`. Este repositório existe só para que o updater embutido no
app consiga verificar e baixar novas versões via API pública do GitHub, sem
precisar de nenhum token/autenticação em cada máquina onde o BEE está
instalado.

Veja a aba [Releases](../../releases) para baixar a versão mais recente.
